# Triage Labels

Les skills parlent en termes de cinq rôles de triage canoniques. Ce fichier associe chaque rôle à l'étiquette réellement utilisée dans le tracker de ce dépôt.

| Étiquette dans mattpocock/skills | Étiquette dans notre tracker | Sens |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Le mainteneur doit évaluer l'issue |
| `needs-info` | `needs-info` | En attente d'information de l'auteur |
| `ready-for-agent` | `ready-for-agent` | Entièrement spécifiée, prête pour un agent autonome |
| `ready-for-human` | `ready-for-human` | Demande une implémentation humaine |
| `wontfix` | `wontfix` | Ne sera pas traitée |

Quand une skill nomme un rôle (p. ex. « apply the AFK-ready triage label »), utiliser l'étiquette correspondante de ce tableau.

Modifier la colonne de droite pour suivre le vocabulaire réellement en usage.
