# Historique des audits et jalons

Ce fichier tenait les 34 premières lignes du `README.md`, avant « Démarrage
rapide » : un lecteur venu pour compiler le binaire lisait d'abord huit campagnes
d'audit (audit DOC-03). Rien n'a été retiré, seulement déplacé.

Chaque ligne renvoie au `CHANGELOG.md` ou à l'ADR qui porte le détail. Les
identifiants cités (`FIB-02`, `OVR-10`, `M-01`…) se résolvent par
[`INDEX.md`](INDEX.md).

☑ **Limites déclarées par la passe du 2026-08-07 — levées toutes deux** (état au 2026-09-23,
EVAL-04). La première l'a été le 2026-09-03 : `-race` tourne sur l'hôte et passe sur tous les
paquets, et `check.ps1` l'active automatiquement quand CGO et un compilateur C sont présents. La
seconde a tenu jusqu'au 2026-09-07 : le 2026-09-04 encore, `GOARCH=386 go build ./...` échouait,
`maxReasonableWords` (`1 << 60`, `internal/fibonacci/memory/arena.go`) débordant un `int` 32 bits.
TYP-01 l'a corrigée (version 4.1.0) ; `386`, `arm` et `arm64` compilent et le job CI `cross-build`
les garde (`PORTABILITY.md` § 1).
`TestStateBump_PinnedAcrossCachedCalls` était *flaky* au même taux sur le commit parent (un test
antérieur laissait une arène surdimensionnée dans le pool d'état global) jusqu'à 4.1.0, qui l'a
corrigé à la cause (`CHANGELOG.md`, 4.1.0).

☑ **Gate rejoué le 2026-09-04 sur `d2aa36a`** (Windows 11, `go1.27.0`, `golangci-lint v2.13.2`) :
`go build`, `go vet`, `go test ./...`, `go test -race ./...` sur les 21 paquets, `gofmt -l .` sans
sortie et `golangci-lint run ./...` à **zéro finding**. Une seule cible reste hors gate sur cet hôte :
`go build -tags gmp`, faute d'en-têtes libgmp (voir le tableau ci-dessus).
⚠ Le relevé du 2026-08-10 annonçait `golangci-lint` à 0 avec la v1.64.8 ; sous `go1.27` ce binaire
**ne peut plus s'exécuter du tout** (`export data version 4`), et les scripts de gate traitaient le
lint comme consultatif — ils affichaient l'échec puis `Overall: PASS`. Le zéro publié restait vrai à
sa date, mais il a cessé d'être vérifié sans que rien ne le signale. Le lint est désormais bloquant.
*Un décompte publié sans avoir été réexécuté n'est pas une mesure ; un outil qui ne peut plus tourner
n'en est pas une non plus.*
